# KhidirID Blog

Personal blog focused on Cybersecurity, CTF writeups, and cloud security labs.

## Tech Stack
- Astro
- React
- TailwindCSS
- Framer Motion
- Chart.js

## Features
- CTF Writeups (HTB, THM, PicoCTF, etc)
- Cloud Security Labs
- Progress Tracking
- Dark Mode
- Responsive Design

## Development
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```

# OSCP Preparation Path

## 1. Introduction

Path OSCP di TryHackMe dirancang untuk mempersiapkan Anda menghadapi ujian OSCP dengan memberikan pemahaman mendalam tentang teknik-teknik yang diperlukan serta praktik langsung dalam bentuk room-room yang menantang.

---

## 2. Prerequisites

Sebelum memulai path ini, pastikan Anda telah memiliki:
- Akun TryHackMe aktif
- Dasar-dasar penggunaan Linux
- Pengetahuan dasar tentang jaringan dan protokol

---

## 3. Recommended Learning Path

### Step 1: Basic Penetration Testing
- **Room: Intro to Penetration Testing**
  - Pelajari dasar-dasar penetration testing, terminologi, dan metodologi yang umum digunakan.
  
- **Room: Linux Fundamentals**
  - Kuasai perintah dasar Linux yang penting untuk penetration testing.

### Step 2: Networking Concepts
- **Room: Networking Basics**
  - Pahami konsep dasar jaringan, termasuk TCP/IP, UDP, dan model OSI.

- **Room: Advanced Networking**
  - Pelajari tentang VLAN, subnetting, dan routing.

### Step 3: Web Application Testing
- **Room: Web Fundamentals**
  - Kenali cara kerja aplikasi web dan teknologi yang umum digunakan.

- **Room: OWASP Top 10**
  - Pelajari tentang kerentanan aplikasi web yang paling kritis menurut OWASP.

### Step 4: Exploitation Techniques
- **Room: Buffer Overflow**
  - Pahami konsep buffer overflow dan cara mengeksploitasinya.

- **Room: SQL Injection**
  - Pelajari teknik SQL Injection dan cara menghindarinya.

### Step 5: Privilege Escalation
- **Room: Linux Privilege Escalation**
  - Kuasai teknik-teknik untuk meningkatkan hak akses di sistem Linux.

- **Room: Windows Privilege Escalation**
  - Pelajari cara-cara untuk meningkatkan hak akses di sistem Windows.

### Step 6: Post-Exploitation
- **Room: Maintaining Access**
  - Pelajari cara menjaga akses ke sistem yang telah dieksploitasi.

- **Room: Covering Tracks**
  - Pahami pentingnya menghapus jejak setelah melakukan eksploitasi.

---

## 4. Tools of the Trade

Dalam perjalanan Anda di path ini, Anda akan diperkenalkan dengan berbagai alat yang umum digunakan dalam penetration testing, antara lain:
- **Nmap**: Untuk pemetaan jaringan dan pemindaian port.
- **Burp Suite**: Untuk pengujian keamanan aplikasi web.
- **Metasploit**: Untuk pengembangan dan eksekusi exploit.
- **Wireshark**: Untuk analisis lalu lintas jaringan.

---

## 5. Tips for Success

- Luangkan waktu untuk memahami setiap konsep dan teknik yang diajarkan.
- Praktikkan secara langsung di lab atau lingkungan yang aman.
- Jangan ragu untuk mencari bantuan atau bertanya jika mengalami kesulitan.
- Selalu perbarui pengetahuan dan keterampilan Anda dengan mengikuti perkembangan terbaru di dunia keamanan siber.
